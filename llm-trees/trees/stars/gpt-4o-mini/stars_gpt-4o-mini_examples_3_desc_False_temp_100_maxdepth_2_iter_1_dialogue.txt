```python
def predict(X: dict):
    # Initialize a list to track truth values of the inner nodes
    nodes = [None, None]  # Two inner nodes
    
    # First decision node based on B-V color index
    nodes[0] = X["B-V"] <= 0.5  # Threshold for B-V
    if nodes[0]:
        prediction = 0  # Classify as dwarf star
    else:
        # Second decision node based on Vmag
        nodes[1] = X["Vmag"] <= 3.0  # Threshold for Vmag
        if nodes[1]:
            prediction = 0  # Classify as dwarf star
        else:
            prediction = 1  # Classify as giant star

    return prediction, nodes
```

### Explanation:
1. The `nodes` list stores the truth values for the two inner nodes based on the conditions checked.
2. The first decision node checks whether the "B-V" feature is less than or equal to 0.5. If true, the prediction is 0 (dwarf star).
3. If the first condition is false, the function checks the second node based on the "Vmag" feature, with a threshold of 3.0. If this condition is true, it classifies as a dwarf star. If not, it classifies as a giant star (1).
4. The function returns the predicted class and a list of truth values for the decision nodes.

```python
def predict(X: dict):
    # Initialize the nodes list with a size of 3, since the tree has 2 internal nodes
    nodes = [None, None]
    
    # First node: Check the credit history rating
    nodes[0] = (X["Credit history rating"] == "A1")
    
    if nodes[0]:
        # If Credit history rating is A1, predict high credit scoring
        prediction = 1  # 1 = high credit scoring
    else:
        # Second node: Check the Debt amount
        nodes[1] = (X["Debt"] <= 5000)
        
        if nodes[1]:
            # If Debt is less than or equal to 5000, predict low credit scoring
            prediction = 0  # 0 = low credit scoring
        else:
            # If Debt is greater than 5000, predict high credit scoring
            prediction = 1  # 1 = high credit scoring
    
    return prediction, nodes
```

### Explanation of the Function:
1. The function takes a dictionary `X` containing the necessary feature inputs.
2. The `nodes` list is initialized with 2 slots to store the truth values of the inner nodes.
3. The first condition checks if the "Credit history rating" is "A1." If true, it sets the prediction to 1 (high credit scoring).
4. If the first condition is false, it checks the "Debt." If the debt is less than or equal to 5000, it sets the prediction to 0 (low credit scoring); otherwise, to 1 (high credit scoring).
5. Finally, it returns the prediction and the list of inner node truth values.

This function adheres to the structure of the decision tree while providing clear outputs for both prediction and node evaluations.

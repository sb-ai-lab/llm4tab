|--- Reason for reading books (Academic Purpose)

This structure allows for a simple bifurcation emphasizing the motivations behind reading, which is likely a determining factor in reading preferences. Based on your request and the provided decision tree structure for classifying reading preferences, here’s a Python function that implements the decision tree. The function will return a single prediction and a list of boolean values representing the truth values of the inner nodes.

### Python Function

```python
def predict(X: dict):
    # Nodes to represent conditions in the decision tree
    nodes = 5 * [None]  # The number of inner nodes in the decision tree
   
    # Condition for the node - Reason for reading books
    nodes[0] = (X["Reason for reading books"] == "Academic Purpose")
    
    # Additional checks can represent the next conditions in a more elaborate tree
    # However, for the depth of 2, we don't need to check further
    
    if nodes[0]:  # If the reason is Academic Purpose
        prediction = 1  # Reads academic books most of the time
    else:  # If the reason is not Academic Purpose
        prediction = 0  # Reads non-academic books

    return prediction, nodes
```

### Explanation of the Function
- **Input (`X`)**: A dictionary where keys are the feature names, and values are the corresponding values.
- **Nodes**: An array initialized to store truth values for inner nodes (`nodes` list). It has 5 entries corresponding to potentially more complex tree nodes, but in this case, we're only using the first one.
  - The first node checks if the `"Reason for reading books"` is `"Academic Purpose"`.
- **Prediction Logic**: 
  - If the condition in `nodes[0]` is true (i.e., the reason is academic), then the prediction is `1` (indicating the person reads academic books).
  - If the condition is false (i.e., any reason other than academic), then the prediction is `0` (indicating the person reads non-academic books).

### Decision Tree Function

```python
def predict(X: dict):
    nodes = 3 * [None]  # Initialize the node list to hold truth values of inner nodes
    
    # Set thresholds for inner decision nodes
    nodes[0] = X["Vibration"] <= 0.5           # Check vibration level
    nodes[1] = X["Temperature"] <= 75           # Check temperature level (only assessed if vibration > 0.5)
    
    if nodes[0]:
        prediction = 0  # Normal Operation
    else:
        if nodes[1]:
            prediction = 1  # At Risk of Failure
        else:
            prediction = 0  # Normal Operation
            
    return prediction, nodes
```

### Explanation of the Function:
1. **Input**: The function takes a dictionary `X` containing the features for prediction.
2. **Node Evaluation**:
   - `nodes[0]`: Checks if `Vibration` is less than or equal to 0.5.
   - `nodes[1]`: Checked only if `Vibration` is greater than 0.5 and determines whether `Temperature` is less than or equal to 75.
3. **Decision Logic**:
   - If `nodes[0]` is True, the prediction is `0` (Normal Operation).
   - If `nodes[0]` is False, it checks `nodes[1]`. If `nodes[1]` is True, it predicts `1` (At Risk of Failure); otherwise, it predicts `0` (Normal Operation).
4. **Return Values**: The function returns the prediction (0 or 1) and the list of truth values for the inner nodes.

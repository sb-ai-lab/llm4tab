```python
def predict(X: dict):
    nodes = 3 * [None]
    
    # Step 1: Check the Temperature condition
    nodes[0] = X["Temperature"] <= 75
    
    # Step 2: If Temperature condition is met, check Vibration condition
    if nodes[0]:
        nodes[1] = X["Vibration"] <= 0.5
        if nodes[1]:
            prediction = 0  # Normal operation
        else:
            prediction = 1  # At risk of failure
    else:
        # If Temperature condition is not met, check Power_Usage condition
        nodes[1] = X["Power_Usage"] <= 200
        if nodes[1]:
            prediction = 0  # Normal operation
        else:
            prediction = 1  # At risk of failure

    return prediction, nodes
```

### Explanation:

- The first condition checks if the `Temperature` is less than or equal to 75. This corresponds to the first decision split.

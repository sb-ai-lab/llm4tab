## Quick Start

```bash
# 1. Clon a repository (e.g. via SSH)
git clone git@github.com:sb-ai-lab/llm4tab.git
cd llm4tab

# 2. Enviroment setup
make setup

# 3. Activate enviroment
make sync

# 4. Create .env file and add keys
cp .env_example .env

# 5. Run app
make run

# 6. To install a new dependency
uv add package-name

# 7. To update packages
uv update
```
